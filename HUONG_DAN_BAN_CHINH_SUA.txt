HƯỚNG DẪN BẢN CODE CÓ COMMENT
============================

1. Mở project
- Giải nén toàn bộ thư mục Tooling WH Sytems.
- Mở Tooling WH Sytems.sln bằng Visual Studio trên Windows.
- Sử dụng .NET Framework 4.6.1 Targeting Pack và DevExpress 19.1
  (project tham chiếu phiên bản assembly 19.1.16.0), như bản gốc.
- Chạy Restore NuGet Packages nếu Visual Studio yêu cầu.
- Chọn Build > Rebuild Solution trước khi chạy.
  Các file exe/dll trong bin được giữ lại từ bản gốc, chưa chứa code vừa sửa.

2. Nội dung đã chỉnh
- Bổ sung comment tiếng Việt dạng XML summary cho 43 form và 1 report:
  tổng cộng 450 hàm/constructor trong phần code xử lý.
- Giải thích các điểm kiểm tra quyền và phân biệt thêm mới/cập nhật.
- Giữ nguyên file Designer.cs, resx, solution, project, tài nguyên,
  tham chiếu thư viện và cấu trúc thư mục hiện có.
- 43 file form/report chỉ thêm comment và chuẩn hóa xuống dòng;
  các token lệnh C# đã được đối chiếu khớp với bản gốc.

3. Async/await
- Form Backup: chuyển nút sao lưu sang async/await, dùng OpenAsync và
  ExecuteNonQueryAsync của SqlClient để không chặn luồng giao diện.
- Thêm BackupDataBaseAsync trong BackupDAO và DataProvider.
- Giữ toàn bộ API đồng bộ cũ để các chỗ gọi hiện tại tiếp tục hoạt động.
- Giữ nguyên câu SQL BACKUP, database ToolWH, tên file .BAK,
  quy tắc thời gian trong tên file và timeout mặc định.
- Khi đang sao lưu: khóa hai nút chọn thư mục/sao lưu, ngăn đóng form;
  sau khi xong hoặc lỗi thì khôi phục trạng thái nút. Lỗi được thông báo,
  màn hình chờ được đóng trong finally.
- Hai form frmInventory và frmInvenSpecPart đã có async trong bản gốc:
  giữ nguyên tác vụ, thứ tự gọi và cách nạp dữ liệu hiện tại, thêm comment.
- Các thao tác nhập/xuất, phân bổ tồn kho, thêm/sửa/xóa và truy cập control
  khác giữ nguyên để tránh thay đổi trình tự nghiệp vụ.

4. Kiểm tra đã thực hiện
- Phân tích cú pháp toàn bộ mã C#: không phát hiện lỗi cú pháp.
- Kiểm tra các file được khai báo trong csproj: không thiếu file.
- Đối chiếu 43 file chỉ thêm comment: câu lệnh C# khớp bản gốc.
- Đối chiếu các hàm DAO cũ: giữ nguyên câu lệnh.
- Không build/chạy được ứng dụng tại môi trường xử lý này vì thiếu
  Windows, .NET Framework và DevExpress. Chưa kiểm thử kết nối SQL Server.

5. Kiểm tra trên máy sử dụng
- Rebuild Solution, đăng nhập và mở các màn hình thường dùng.
- Kiểm tra nhập/xuất, thêm/sửa/xóa, thống kê và xuất Excel với dữ liệu thử.
- Chọn thư mục sao lưu có quyền ghi đối với dịch vụ SQL Server.
- Thử sao lưu thành công và trường hợp đường dẫn không hợp lệ;
  kiểm tra thông báo, file .BAK và trạng thái nút sau khi hoàn tất.
